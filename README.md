# JEM — 편집샵 커뮤니티 + B2B 도매 플랫폼

의류·가방 편집샵을 위한 **소비자 커뮤니티**(가게 소개) + **가게 관리자용 B2B 도매장**(가게끼리 주문, 본사 경유).

## 실행

```bash
npm install
npm start
```

- 소비자 사이트: http://localhost:4600
- 가게/본사 관리자: http://localhost:4600/admin

서버 최초 실행 시 `data/jem.db`가 없으면 샘플 데이터가 자동 시드됩니다.

## 데모 계정

| 구분 | 아이디 | 비밀번호 |
|------|--------|----------|
| 플랫폼(본사) | `jem` | `jem1234` |
| 가게 | `moodshop` `linea` `gentleman` `lederhouse` `carrybag` `solemate` | `shop1234` |

> 실서비스 전 반드시 비밀번호와 `SESSION_SECRET`(환경변수)을 교체하세요.

## 화면 방향

- **소비자 사이트(`/`)**: 모바일 우선 (480px 폭 중심)
- **관리자(`/admin`)**: **데스크탑 레이아웃** — 좌측 세로 사이드바 내비 + 넓은 콘텐츠(피드는 화면 폭에 따라 2~4열 그리드). 창이 좁아지면(≤820px) 사이드바가 상단 가로 내비로 접히는 반응형.

## 기능

**소비자 (공개)**
- 카테고리(여성/남성/가방/신발·잡화) → 가게 목록 → 가게 상세
- 가게 상세: 오늘의 신상 / 대표 물품 + 카카오·텔레그램 문의

**가게 관리자**
- 로그인(본사가 발급한 계정)
- 내 상품: 업로드(사진·가격·구분), **무료 10개 한도** 미터, 삭제
  - 한도 초과 시 업로드 잠금 + 안내 (과금은 미구현 — 추후 유료 플랜 자리 마련)
- B2B 피드: 전 가게의 매일 상품 피드(카테고리/신상·대표/오늘 필터), 다른 가게 상품 **주문**
- 주문: 보낸 주문 / 받은 주문(수락·발송·완료·취소 상태 변경)
- **내 정보**: 프로필 직접 수정(한줄소개·지역·소개·카카오/텔레그램·전화·주소·지도) + **커버 사진 업로드**(자동 최적화). 수정 즉시 소비자 페이지에 반영
  - 가게명·카테고리는 본사에서 관리 (프로필 화면에선 읽기전용)

**플랫폼(본사)**
- **공급 상품**: 가게에게 뿌릴 도매 상품 업로드(카테고리 지정, 한도 없음)/삭제 — B2B 피드에 "본사 공급" 뱃지로 노출, **소비자에게는 안 보임**
  - 등록 상품을 **일별 / 주별 / 월별**로 구분해 보기 (등록일 기준 그룹, 각 그룹 개수 표시)
- **공급 정산(대금청구용)**: 공급 상품 주문을 추적. 요약 카드(총 주문·총 청구액·확정 대기) + **가게별 청구 요약**(건수·수량·청구액) + **건별 상세 내역**(일자·가게·상품·수량·단가·금액·상태·메모). **기간(전체/이번달/지난달)·상태** 필터. 청구액은 취소 건 제외.
  - 금액은 단가 텍스트("도매 8,000원")에서 숫자를 파싱해 × 수량으로 계산 — 정밀 정산이 필요하면 상품·주문에 **숫자 가격 컬럼**을 추가하는 것을 권장(현재는 자유 텍스트 단가).
- 전체 가게 목록(상품 수), **전체 주문 집계(모든 주문은 본사 경유)**, 가게 **계정 발급**

> 노출 규칙: 소비자 API(`/api/shops*`)는 `role='shop'`만 조회 → 본사 공급 상품은 로그인한 가게 사장의 B2B 피드에서만 보임. 카테고리 필터는 `COALESCE(상품.category, 가게.category)`로 동작(본사 상품은 상품별 카테고리, 가게 상품은 가게 카테고리).

## 속도 / 이미지 최적화

빠른 로딩을 기본값으로 유지하기 위해 업로드 이미지를 서버에서 자동 처리합니다.

- **업로드 즉시 리사이즈 + WebP 압축** (`sharp`)
  - 상세용: 최대 1200px, WebP q78
  - 목록·피드용 **썸네일**: 500×500 크롭, WebP q72
  - EXIF 방향 자동 보정(폰 사진 대응)
- **목록/피드/카드는 썸네일만 로드**, 상세 이미지는 필요할 때만
- **장기 캐시**: `/uploads`는 `Cache-Control: immutable, max-age=1년` (파일명이 고유해 안전)
- `<img loading="lazy" decoding="async">`로 화면 밖 이미지는 나중에 로드

실측 예: **9.6MB 원본 사진 → 상세 252KB + 썸네일 27KB**. 원본은 저장하지 않습니다.
(업로드 원본 허용 상한 8MB — 어차피 압축 저장)

## 아직 안 만든 것 (설계상 자리만 마련)

- **과금 로직**: 10개 초과 업로드/유료 플랜 결제. `shops.product_limit`을 올리면 한도가 늘어나는 구조 — 결제 연동만 추가하면 됨.
- **중간 유통 마진 계산/정산**: 주문은 전부 본사가 조회 가능(경유). 마진율·정산 금액 계산은 추후.
- 이미지 CDN, 실서비스용 세션 스토어(현재 메모리 — 서버 재시작 시 로그아웃), HTTPS 등 배포 항목.
